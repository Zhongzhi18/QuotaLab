# Third-party software

The Windows package contains the CPython runtime, the PyInstaller bootloader and
runtime hooks, and IANA time-zone data distributed as `tzdata`.

Their license texts are included in the portable package under `licenses/`:

- `Python.txt`: Python Software Foundation license and bundled notices.
- `PyInstaller.txt`: PyInstaller license, including its bootloader exception.
- `tzdata.txt` and `tzdata-Apache.txt`: the time-zone data package notices.

QuotaLab's own source is covered by the [MIT license](LICENSE).
