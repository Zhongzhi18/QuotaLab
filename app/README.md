# 应用源码

QuotaLab v1.0.0 的 Python 服务、网页界面和测试都在这里。

- `quota_lab.py`：启动入口与本机服务。
- `ui_*.js`、`ui_preview.html`、`styles/`：界面和交互。
- `tests/`：规划、提醒、双语页面等回归测试。
- `packaging/`：Windows 版本资源；旧文件用于保留历史测试。
- `scripts/`：底层构建兼容入口，日常请用仓库根目录的 `scripts/`。

使用方法请看[项目首页](../README.md)，构建和数据兼容说明见[开发说明](../docs/开发说明.md)。
