# 开发与构建

应用源码在 `app/`，根目录 `scripts/build-windows.ps1` 构建 Windows ZIP，`scripts/check-windows-package.ps1` 检查解压后的版本、启动和本机接口。

Windows 使用 Python 3.14.0；构建依赖固定在 `app/requirements-build.txt`。运行时的 IANA 时区数据由 `tzdata` 提供。

v1.0.0 沿用 r31 的本机数据目录 `%LOCALAPPDATA%\QuotaLab-dev-v0143` 和单实例标识，避免升级后看不到已有计划。该目录名是兼容设置，不是当前显示版本；界面和接口版本均为 1.0.0。请退出旧版后再升级。

历史测试和底层构建文件中的 r14–r31 名称保留，用来追溯回归问题。新发布入口不需要了解这些历史编号。

工作流在 `.github/workflows/windows-release.yml`，GitHub 按约定从这里读取。可以手动运行 main 分支测试；推送 `v1.0.0` 标签会重新验证并生成发布草稿，由维护者核对资产后发布。

集中回归和浏览器测试使用隔离临时目录和模拟数据。桌面原生窗口另有显式本机检查脚本 `app/scripts/check_desktop_window_r31.py --native-window`，会弹出短暂测试窗口，不适用于无交互桌面的 CI。
