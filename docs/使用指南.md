# QuotaLab 使用说明

QuotaLab 帮你回答三个问题：现在还有多少 Codex 额度？下一段工作应该什么时候安排？之前的安排和工作结果是什么？

第一次打开时，可以照着同文件夹里的“首次使用.txt”走一遍；仓库中对应的是[首次使用](首次使用.md)。先保存一段未来的工作时间、试一下桌面提醒，再慢慢探索其他页面。

它适合经常使用 Codex、会遇到额度限制、希望提前安排较长工作时段的人。实际编程、写作或研究仍在 Codex 中完成，QuotaLab 用来查看和规划。

## 第一次使用：用一个具体例子走完

1. 完整解压下载的 ZIP，双击 QuotaLab.exe。保留旁边的 _internal 文件夹。
2. 在“概览”看额度。比如剩余 96%、距离重置约 4 小时：这些是当前账户返回的读数，不代表保证还能工作几小时。留意更新时间；五小时和周额度分别计算。读不到额度时仍可以先安排时间。
3. 点击“安排工作”，填一个你真正需要 Codex 的时段。例如名称“整理项目”，日期选明天，09:00 开始、12:00 结束，强度选“中等”。右侧立刻显示“3 小时”，便于检查输入；这只是计划时长。
4. 点击“保存安排”。右侧显示使用建议或需要更新的原因，下方可看到保存的安排。根据提示考虑调整时间或强度；资料不足时不会给出确定结论。
5. 到时间后，在 Codex 中开展实际工作。QuotaLab 的保存按钮不会发送任务、购买额度或制造重置。
6. 工作开始后，到“使用洞察 → 记录工作结果”，选这段计划，填写完成/部分完成/未完成和实际用时。这样你以后可以回看自己的工作节奏。

你不必先学会所有页面。第一次只用“概览”和“需求规划”即可。页面顶栏的“使用指南”随时可以重新打开，按 Escape 关闭。

## 每个页面解决什么问题

| 页面 | 什么时候用 | 可以做什么 |
| --- | --- | --- |
| 概览 | 开始工作前 | 看当前额度、重置读数、今天与明天的安排，进入规划 |
| 需求规划 | 需要提前留时间时 | 填日期、时段、强度；即时核对计划时长；保存并看建议 |
| 使用洞察 | 工作开始后、定期回顾时 | 看真实额度观测，主动记录工作结果和实际用时 |
| 节奏预测 | 安排未来几天时 | 切换 3/7/30 天，查看已保存的工作负荷；不会预测官方未来额度 |
| 额度动态 | 怀疑有公开服务事件时 | 主动启用公开信息读取后手动查看；它不证明你的个人额度恢复 |
| 历史记录 | 想回看安排或建议变化时 | 查看保存的计划与相关变化 |
| 设置 | 额度读不到、要调整偏好或退出时 | 重新读取、连接排查、保存偏好、退出程序 |

## 交互规则

- 日期过期：跨天后草稿可能仍保留昨天的日期。“尚未保存：开始时间已过去”表示没有保存这次输入；请主动改日期或开始时间，再保存。右侧旧建议不代表新草稿已经保存。
- 保存结果：服务明确拒绝时显示“未保存”；只有网络中断等无法确认的情况才显示“尚未确认”，此时重试同一次提交可避免重复。已保存但列表刷新失败时只需刷新页面。
- 两类任务不混用：“已保存的安排”只列出本机工作计划，不读取或同步官方任务。生成说明也不等于创建官方任务。

- 多个计划：保存后右侧自动查看该计划的建议。已保存列表的“查看建议”按钮切换查看对象，不会修改左侧草稿；“正在查看”标记对应当前建议。建议暂不可用时不会拿其他计划代替。
- 提醒归属：成功反馈应同时列出计划名称、开工时间、提醒时间。右侧可查看及取消所选计划已有的有效提醒；新建计划不会自动迁移或取消旧计划提醒。

- 跨午夜：开始 23:00、结束 01:00 表示次日 01:00 结束，预览会提示。开始结束相同的时段不能保存。
- 草稿：填写后切页回来会保留本次浏览器会话里的输入；只有点“保存安排”才成为已保存计划。
- 保存与建议：额度不足/读数缺失并不等于计划丢失。检查“已保存的安排”，再根据建议调整工作。
- 提醒：如果当前建议提供提醒入口，可主动设置。默认是网页内提示。若要最小化或关闭网页后仍提醒，请在“工作时段与提醒”或设置页启用“Windows 桌面开工提醒”，保持勾选“独立桌面提醒窗口”，发送测试通知并亲眼确认。独立窗口不属于浏览器，会持续显示直到关闭，不会抢走键盘焦点；系统通知仍受 Windows 勿扰设置影响。后台必须运行，休眠或关机时不能提醒。“窗口已创建”不等于你已看到。
- 展开状态：“更多设置（可选）”现在使用固定控件标识并在模块重建后恢复；自动刷新、语言切换和工作/官方任务标签切换不应改变你主动选择的展开或收起状态。草稿仍按既有说明保留，不自动同步官方任务。
- 桌面通知隐私：默认静音、隐藏计划名；需显示计划名称时单独勾选，锁屏可能可见。设置和提醒提交去重记录只保存在本机，不上传。若通知宿主失败，可关闭再启用桌面提醒并重测，不要关闭系统安全保护。
- 观测不足：初次使用时没有历史曲线、完成率或常见时段是正常的。数据来自实际观测与主动记录，不会自动编造。
- 百分比：96% 是额度窗口的剩余比例，不能换算成确定的工作小时数或任务数量。

## 我想让 AI 到点做事，而不只是保存时段

这三种行为不同：保存工作计划只记录时段；本地提醒只通知你；官方定时任务才会按设置执行 AI 工作。QuotaLab 不会因为你保存了计划就创建官方任务。

1. 在“需求规划”顶部切换到“官方定时任务工作台”。默认只需填写任务内容及重复、日期、时间；模板、名称、资料范围、输出标准与执行偏好都在“更多设置（可选）”中。
2. 填写具体任务，例如“检查项目测试结果，汇总失败原因，不修改文件”。选择仅一次、每天或工作日，并核对首次日期、时间和显示的本机时区。
3. 点击“生成并核对说明”，再“复制设置说明”。有特殊需求时再展开更多设置。这些操作只在页面中整理文本，不发送任务、不运行模型，也不消耗 AI 额度。偏好只写入说明，尚未在官方应用生效。草稿只在本次页面内存中保留，关闭页面后消失。
4. 在官方 ChatGPT / Codex 应用中粘贴，请它按说明准备定时任务；核对其创建窗口中的描述、重复、时间、时区、模型、通知、本地运行和聊天选项，确认后创建。以官方应用显示的任务为准，不是以 QuotaLab 生成说明为准。
5. 涉及本机文件时选择相应项目，保持电脑开机、官方桌面应用运行；网页版不能直接访问本机项目文件。先手动测试描述，再观察最初几次定时运行。

这不是“到额度恢复时自动触发”的连接器：定时运行不能保证届时额度充足，QuotaLab 后续建议变化也不会自动修改官方任务。实际创建入口和可用选项取决于官方应用及账户；不要在任务描述中填密码或密钥。

官方说明：https://learn.chatgpt.com/docs/automations （联网打开）

## 打开、重开与退出

- 快速连续双击 EXE，12 秒内相同工作台地址只打开一次，已有后台服务会被复用。
- 关闭浏览器标签不会自动退出后台程序。若要彻底退出，在“设置 → 更多设置 → 退出 QuotaLab”操作。
- 关掉标签后想重新打开，等待上述 12 秒去重时间结束，再双击 EXE；也可使用浏览器收藏的本机工作台地址。
- 127.0.0.1 是这台电脑上的工作台地址。必须先启动程序，直接打开网址不会替你启动后台。
- 升级时先退出旧版，将新 ZIP 解压到新文件夹。不要混用不同版本的 EXE 与 _internal。

## 数据和边界

计划、结果和历史保存在这台电脑；换电脑不会自动同步。普通规划流程不会替你运行 Codex 任务。公开服务动态是可选的联网读取。

遇到连接失败，先确认 Codex 已安装并已登录，再到设置重新读取。真实账户返回什么窗口就显示什么，不按 Free/Plus/Pro 名称猜测。无法自动发现时再使用连接排查。

向维护者反馈时，提供版本、操作步骤、预期和实际结果即可。不要上传账户凭据、完整邮箱、私人任务内容或本地数据目录。
