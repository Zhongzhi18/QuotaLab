# 跟着做一遍：第一次安排工作

目的：确认“看额度 → 保存计划 → 提醒 → 工作 → 自报结果 → 重开仍保留”确实可用。不要用额度下降来判断效率，也不需要为了测试刻意消耗额度。

## 准备

退出旧版，完整解压下载的 ZIP，双击 QuotaLab.exe，确认左上角 v1.0.0。保留旁边的 _internal 文件夹。接下来保持电脑开机、QuotaLab 后台运行。已有旧计划时，可以用列表按钮切换查看对应建议。

如果要验证最小化后的提示，请先在“工作时段与提醒”或设置页启用“Windows 桌面开工提醒”，保持勾选“独立桌面提醒窗口”，发送测试通知后最小化浏览器。桌面应有独立窗口，直到你关闭；点击“打开工作台”可返回网页。未启用时仍只有网页提示。系统通知可能受 Windows 设置限制，但独立窗口是另一个应用窗口，不依赖浏览器。退出后台、休眠或关机后不能提醒。

展开“官方定时任务工作台 → 更多设置（可选）”，填写一项范围后点击标题使输入框失焦，等待至少 15 秒，确认仍展开且文字保留；主动收起后再等 15 秒，也应维持收起。

## 一步步操作

1. **概览**：记下五小时剩余、周剩余和读取时间。数据以你当时的账户为准，不必与截图数字一样。读数缺失时应明确提示，不该编造百分比。
2. **需求规划**：名称填“首次验收：整理一段说明”。日期选今天，开始设在当前时间的 **10 分钟后**，结束设在开始的 **10 分钟后**，强度选“轻度”。例如现在 14:00，就填 14:10–14:20。临近午夜时日期及次日结束提示应正确。右侧应预览 10 分钟；这是工作计划时长，不是保证可用额度。
3. **保存安排**：只点一次。应看到成功反馈和一条已保存安排。记住这个独特名称；已有旧计划时，总计划数会增加 1，不一定显示总数 1。建议可能让你继续观察或调整，这不等于保证完成；不要求固定某一句建议。
4. **检查提醒**：如果这条当前建议提供“开工前提醒我”，选择“提前 5 分钟”并点击。应出现确切提醒时间（例如 14:05）。不要只看到按钮变色就当作成功。如果建议过期、时段冲突或没有入口，先按建议处理、重新读取后再试，不绕过限制。
5. **等待提醒**：若已启用并验证桌面通知，可以最小化或关闭网页，但保持 QuotaLab 后台运行；约 5 分钟后应检查 Windows 桌面是否提示。未启用时必须保持网页可见。提醒不会自动启动 Codex 或执行任务；退出后台、电脑睡眠/关机时不能依赖它。
6. **到开始时间工作**：例如 14:10，自己在 Codex 中进行一项真正有用的低风险操作：“请把我提供的这段说明整理成 5 条要点，不修改任何文件。”提供一段不含隐私的文字即可。QuotaLab 不负责自动发送这条指令。
7. **使用洞察 → 记录工作结果**：必须等计划开始后。选“首次验收：整理一段说明”，按实际情况选完成/部分完成/未完成，填写真实用时（例如确实用了 3 分钟就填 3），点击保存。应显示自报结果保存成功，已记录结果数量增加；样本不足时不应立刻出现完成率或高效时段结论。
8. **跨页复查**：历史中应保留该名称；内部重算过程在“查看原始变化记录”中，不能被误认为新增了多个计划。节奏预测只计算未来或尚未结束的工作部分，所以测试完后不一定仍显示完整 10 分钟。
9. **重开验证**：刷新页面，结果数量应保留。通过“设置 → 更多设置 → 退出 QuotaLab”退出，再双击同一新版 EXE，计划和结果仍在。快速连续启动两次，12 秒内不应额外打开第二个工作台。

## 定时任务说明准备器（可选，和上面分开）

进入需求规划顶部“官方定时任务工作台”：描述填“整理我提供的说明，只输出摘要，不修改文件”，选择仅一次和将来的日期时间，点击“生成并核对说明”并复制。其余字段默认折叠在“更多设置（可选）”。生成后修改时间，旧说明应隐藏，必须重新生成。此时 **没有创建官方任务**；你需要在官方应用中核对并确认。此页不读取或同步官方任务列表。只验证这个准备器时，不必创建真实任务。草稿关闭页面后不保留。

## 保存问题复测

先把工作计划日期填为昨天并保存，应明确提示“尚未保存：开始时间已过去”，不能显示网络不确定或新增安排。然后改为明天，名称填写“r30 保存验收”，保存后在已保存列表中找到同名计划，右侧标题也应一致；刷新页面后仍应存在。
