# QuotaLab v1.0.0

这是 QuotaLab 的第一个公开版本：看清当前额度，安排下一段工作，到点提醒，做完再回顾。

## 下载

Windows 64 位用户请选择 **QuotaLab-1.0.0-Windows-x64.zip**，完整解压后运行 **QuotaLab.exe**。同页的 **QuotaLab-1.0.0-SHA256.txt** 可用于核对下载文件。

程序为便携版，尚未签名。源码下载入口面向开发者，日常使用请选择上面的 Windows ZIP。

## 这次包含什么

- Codex 额度概览、多计划管理和开工提醒。
- 独立桌面提醒窗口：最小化或关闭网页后，后台仍可提醒。
- 工作结果记录、历史回看和未来工作负荷查看。
- 官方定时任务说明准备、中英文和深浅色界面。
- 修复高级设置自动收起、跨天草稿保存提示和建议归属等交互问题。

从 r31 升级时，先在设置里退出旧版，再运行新版；已有计划和提醒继续使用原数据目录。
