先看清额度，再安排重要工作。

QuotaLab 读取本机 Codex 客户端返回的额度窗口，帮你把工作时段安排得更踏实。计划由你掌控，任务仍由你在 Codex 中启动。

查看下载与版本 浏览源代码

当前为 Windows x64 便携预览包，不是安装器；请下载完整 ZIP 并核对随附的 SHA256。尚未提供 macOS 或 Linux 原生包。

是否已开放下载，以 Releases 页面实际显示为准。若还没有 r22 Release，请勿把 GitHub 的 “Source code” 压缩包当成可直接运行的应用。

本机读取

额度由已登录的 Codex 客户端提供。没有返回的窗口会明确显示不可用，不用套餐名称猜额度。

你来安排

计划和建议保存在这台电脑上。QuotaLab 不会替你启动 Codex、创建官方任务或发送模型请求。

隐私边界清楚

仪表盘只绑定本机回环地址，不是托管在网上的应用。没有默认遥测或历史上传；手动刷新公开状态会向官方状态站点发起请求。

本地应用网址不是公开网站地址 解压并启动 QuotaLab 后，仪表盘默认打开 http://127.0.0.1:18861/。GitHub 页面只负责介绍、下载和支持信息，无法连接你的电脑或读取本机数据。

QuotaLab 为独立社区项目，与 OpenAI 或 Codex 官方无隶属关系。

本机数据默认不加密存储。分享诊断信息前请先检查内容并移除账户信息。
